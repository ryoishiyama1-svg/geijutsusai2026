# 芸術祭 公式サイト

麻布学園「芸術祭」の公式サイトです。

- 公開URL： https://ryoishiyama1-svg.github.io/geijutsusai2026/
- 過去の年のページ： URLの末尾に `?year=2026` のように年をつける

URLはパンフレットやポスターのQRコードに入っているので、変えないでください。

---

## ファイルのしくみ

| ファイル | 中身 | 毎年さわる？ |
|---|---|---|
| `data/2026.js` など | その年の記録（日時・出演団体・タイムテーブル・お礼の文・来場者数・写真） | **毎年1つ増える** |
| `data/site.js` | 芸術祭そのものの説明（芸術祭とは）、連絡先、`YEARS`（載せる年の一覧） | 年を足すときだけ |
| `data/template.js` | 新しい年のひな形（サイトでは読み込まれない） | コピーして使う |
| `data/select.js` | どの年を表示するか決める部分 | さわらない |
| `index.html` | ページのデザインと動き | ふだんはさわらない |
| `images/` | 写真・メインビジュアル | 年ごとに `images/2027/` のようにフォルダを分けると整理しやすい |

## 毎年の更新のしかた

### 1. 新しい年の準備（開催が決まったら）

1. `data/template.js` をコピーして、`data/2027.js` のように **年の名前** にする
2. `data/site.js` の `YEARS` に年を足す（新しい年を左に）
   ```js
   const YEARS = [2027, 2026];
   ```
3. `data/2027.js` の中身を書く
   - `edition` …… 第何回か
   - `status: "upcoming"` …… 開催前のあいだはこのまま
   - 日時・会場・出演団体（`program`）・ごあいさつ・注意事項など
   - まだ決まっていない所は `【要入力】` のままでOK（サイトでは「近日公開」と出る）

これでトップページが新しい年に切り替わり、カウントダウン・見どころ・注意事項・FAQ・カレンダー登録が出ます。前の年は自動で「これまでの芸術祭」に並びます。

### 2. 出演団体がかわったとき

`program` の1行が1団体です。`end`（終わりの時間）がある行がステージとして、出演カードにもなります。

- `band` / `dj` / `live` / `dance` / `drama` は色が決まっている
- 新しいジャンルは `kind` を英字で作って、`label`（表示名）と `color`（色）を書く
  ```js
  { start: "13:00", end: "13:40", title: "合唱", kind: "chorus", label: "CHORUS", color: "#4fa3e0", performer: "合唱部", comment: "ひとこと", photo: "images/2027/chorus.jpg" },
  ```
- 出演者の **名前は載せない**（人数だけ `memberCount` で出せる）

### 3. 当日が終わったら

`data/2027.js` で次の所を書きかえる。

- `status: "done"`
- `attendance: 来場者数`
- `report` …… 共同代表からのお礼の文
- 時間がずれたら `program` の時間を実際の時間にして、`programNote` に一言（例：「当日は予定より10分遅れで進行しました。」）
- 写真を `images/2027/` に入れて、`photos` に足す
  ```js
  photos: [
    ["images/2027/photo1.jpg", "軽音のステージ"],
  ],
  ```

トップに「THANK YOU! 来場者数」が出て、開催前だけの欄（見どころ・注意事項・FAQなど）は自動で消えます。

## 公開のしかた

**かんたんな方法（GitHubのサイト上で直す）**

1. このリポジトリをGitHubで開く
2. 直したいファイル（例：`data/2027.js`）を開いて、右上の鉛筆マークで編集
3. 下の「Commit changes」を押す → 1分ほどで公開サイトに反映

写真は、フォルダを開いて「Add file → Upload files」から追加できます。

---

## 公開してはいけないもの

- 出演者・部員の名前が入ったファイル（パンフレットのデータなど）
- 協賛のご提案資料など、外部に出さない資料

このリポジトリはだれでも見られる（公開）設定です。
